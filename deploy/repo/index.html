Go Savvy packages

Install Go Savvy from a signed apt or dnf repository, and get new versions with your regular system updates.

Debian & Ubuntu

apt, amd64. Debian 13 or later.

1. Add the repository

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/savvy-go.asc @SITE_URL@/savvy-go.asc
echo "deb [signed-by=/etc/apt/keyrings/savvy-go.asc] @SITE_URL@/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/savvy-go.list

2. Install

sudo apt update
sudo apt install savvy-go

Update

sudo apt update && sudo apt upgrade savvy-go

Fedora, RHEL & openSUSE

dnf, x86_64.

1. Add the repository

sudo curl -fsSLo /etc/yum.repos.d/savvy-go.repo @SITE_URL@/savvy-go.repo

2. Install

sudo dnf install savvy-go

Update

sudo dnf upgrade savvy-go

After installing, Go Savvy runs as the savvy-go service on 127.0.0.1:8080. The repository metadata is signed with this key. It keeps the last stable releases; older ones and the standalone binaries are on GitHub Releases. More in the deployment docs.
